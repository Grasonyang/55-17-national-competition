| 分類 | 常見屬性                                                            | 用途            |
| -- | --------------------------------------------------------------- | ------------- |
| 狀態 | `aria-checked`、`aria-disabled`、`aria-selected`、`aria-expanded`  | 告訴使用者目前狀態     |
| 隱藏 | `aria-hidden`                                                   | 對螢幕閱讀器隱藏這個元素  |
| 標籤 | `aria-label`、`aria-labelledby`、`aria-describedby`               | 為元素提供文字說明或標題  |
| 結構 | `role="tablist"`、`role="dialog"`、`role="alert"`、`role="button"` | 給自訂元件補語意角色    |
| 互動 | `aria-controls`、`aria-haspopup`、`aria-live`                     | 連結不同區塊或提示動態內容 |
